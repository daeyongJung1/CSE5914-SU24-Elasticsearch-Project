# CSE5914-SU24-Elasticsearch-Project

# Presentation slides are in "Presentation slides" folder

# To start the JS backend (in the elasticsearch-backend directory)
``` cd elasticsearch-backend ```
``` npm install ```
``` npm run dev ```

# To start the React Frontend (in the elasticsearch-frontend directory)
``` cd elasticsearch-frontend ```
``` npm install ```
``` npm start ```

# To start the Python backend (in the root directory)
If you're using Pip, run: 
``` pip install -r requirements.txt ```
``` py allergen_checker.py ```
